# NO ONE'S CITY — Founders landing page

Русскоязычная одностраничная статическая версия сайта. Не требуется Node, npm или backend.

## Как открыть

Откройте `index.html` в браузере или запустите локальный сервер из папки сайта:

```bash
python3 -m http.server 8080
```

Затем откройте `http://localhost:8080`.

## Как разместить

Содержимое папки можно публиковать через GitHub Pages, Cloudflare Pages, Netlify или любой статический хостинг. Не требуется сборка. Не забудьте добавить канонический URL и og:image, когда будет известен домен.

## Важно: заявки

Это **рабочий прототип отправки через Instagram Direct**, а не автоматический сбор заявок. Форма подготавливает текст, копирует его в буфер и открывает Instagram `@no.ones.city`. Посетитель должен **вставить и вручную отправить** текст в Direct. Никаких заявок сайт сам не сохраняет, номер места не выдаёт и не отправляет в таблицу.

Для первого автоматического сбора рекомендуем подключить Google Forms (ответы -> Google Sheets) или Supabase с защитой от спама, а после этого заменить обработчик формы на реальный подтверждаемый submit. **Не пытайтесь отправлять прямо из браузера в Google Sheets с публичным секретным API-ключом.**

Не публикуйте якобы занятые/свободные места, пока не подключена база. Тексты этапов — планы, не готовые функции.

## Изменение ссылок

Ищите в `index.html` `https://www.instagram.com/no.ones.city/`. Это публичная страница проекта.

## Файлы

- `index.html` — вся страница, стили и логика формы
- `favicon.svg` — лаконичная иконка
- `assets/hero.webp` — ранее утверждённый визуальный концепт города
- `assets/masterplan.webp` — концептуальный генеральный план
- `assets/brand.webp` — эмблема (резерв для дальнейшего дизайна)

## Обновление: TEXT TO HOME / TEXT TO AVATAR

Добавлен раздел с описанием создания концепта дома и персонажа по текстовому запросу. Форма заявки теперь содержит два поля: обязательное описание дома и необязательное описание персонажа. Обновлён текст, копируемый для Instagram Direct.

**Иллюстрация намеренно не выбрана.** В блоке `#create` расположен стилизованный placeholder `.create-art-slot`. После утверждения изображения заменить его тегом `<img>` с локальным файлом в `assets/`, сохраняя адаптивность. Не выдавать AI-концепт за готовую игровую модель.
