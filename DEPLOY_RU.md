# NO ONE'S CITY — GitHub Pages

1. На GitHub создай новый PUBLIC-репозиторий `no-ones-city`.
2. Загрузи **содержимое** этого архива в корень репозитория (index.html, favicon.svg, assets/), не папку поверх корня.
3. Settings → Pages → Build and deployment: Deploy from a branch → main → /(root) → Save.
4. Дождись зелёного статуса и открой `https://<username>.github.io/no-ones-city/`.
5. Проверь на iPhone изображения, меню и кнопку заявки.

Текущая кнопка заявки не сохраняет сообщения в таблицу автоматически — она готовит текст для Instagram Direct.

**Не публикуй здесь секреты и ключи ботов.**
