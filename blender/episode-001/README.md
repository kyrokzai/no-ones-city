# NO ONE'S CITY — Blender M0.1 (Episode 001)

Первый 3D-район города. Стиль: **Modern Low-Poly × Cozy Cinematic × Sunset City**.
Без средневековья, фэнтези и фотореализма.

## Содержимое

| Путь | Что это |
|---|---|
| `scripts/build_district.py` | Скрипт, который строит всю сцену с нуля |
| `scenes/noc_ep001_district.blend` | Сохранённая сцена (Blender 4.2) |
| `renders/test_frame_1080x1920.png` | Тестовый кадр 9:16 для Reels |

## Что в сцене

- **12 домов** трёх типов: с консольным вторым этажом, двухэтажный с односкатной крышей, одноэтажный со стеклянной студией на крыше. У каждого светящиеся окна, дверь, навес, гараж, газон, подъездная дорожка, живая изгородь и дерево во дворе.
- **4 свободных участка**: грунт, золотая светящаяся пунктирная граница, колышки по углам и знак «+».
- **Дороги** с разметкой, тротуары с разрывами на перекрёстках, зебра.
- **Центральная площадь**: фонтан, золотое кольцо, скамейки, фонари.
- **Деревья**: низкополигональные кроны, есть розовые и золотые.
- Уличные фонари, набережная, озеро с отражениями, силуэт небоскрёбов за озером, холмы.
- **Освещение**: закатное небо (тёмно-синий → сиреневый → розовый → золотой), низкое золотое солнце с диском у горизонта, холодная синяя подсветка, тёплые окна и фонари.
- **Камера** `Cam_Reels`: 1080×1920, объектив 30 мм, вид сверху-сбоку через район на закат.
- **Рендер**: Cycles (CPU), 96 сэмплов, шумоподавление, цветовой профиль AgX, мягкое свечение (Glare) в композиторе.

Коллекции в сцене: `Houses`, `FreePlots`, `Roads`, `Plaza`, `Trees`, `Lamps`, `Lights`, `Ground`, `Background`.

## Как запустить

Нужен Blender 4.x (проверено на 4.2). Скрипт **очищает текущий файл** и строит сцену заново.

```bash
cd blender/episode-001
blender -b -P scripts/build_district.py -- \
  --save scenes/noc_ep001_district.blend \
  --render renders/test_frame_1080x1920.png --samples 96
```

Другие параметры:
- `--preview` — рендер в половинном разрешении для быстрой проверки;
- `--samples N` — количество сэмплов;
- `--seed N` — другая случайная расстановка деревьев и окон.

Из интерфейса Blender: вкладка **Scripting** → открыть `build_district.py` → **Run Script**. Сцена будет построена, рендер и сохранение не запустятся.

Без установленного Blender можно использовать Python-модуль `bpy` (нужен Python 3.11):

```bash
python3.11 -m venv bpyenv && bpyenv/bin/pip install bpy==4.2.0
bpyenv/bin/python scripts/build_district.py --save ... --render ...
```

Рендер 1080×1920 при 96 сэмплах занимает около 2 минут 15 секунд на 4 ядрах CPU.
