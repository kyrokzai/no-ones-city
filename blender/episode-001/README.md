# NO ONE'S CITY — Blender M0.3 (Episode 001)

Первый 3D-район города. Стиль: **Modern Low-Poly × Cozy Cinematic × Sunset City**.
Без средневековья, фэнтези и фотореализма.

## Содержимое

| Путь | Что это |
|---|---|
| `scripts/build_district.py` | Скрипт, который строит всю сцену с нуля |
| `scripts/animate_camera.py` | M0.3: правки поверх готовой сцены + пролёт камеры 15 с, проверка траектории, рендер превью |
| `scenes/noc_ep001_district.blend` | Сохранённая сцена (Blender 4.2): район M0.2 + правки M0.3 + `Cam_Cinematic` |
| `renders/m0.3_control/` | 5 контрольных кадров M0.3 (540×960) |
| `renders/m0.3_control_sheet.png` | Те же 5 кадров на одном листе |
| `renders/m0.3_preview_540x960_12fps.mp4` | Облегчённое видео-превью |
| `renders/m0.2_test_frame_1080x1920.png` | Тестовый кадр M0.2, 9:16 для Reels (текущий) |
| `renders/m0.1_test_frame_1080x1920.png` | Тестовый кадр M0.1 (для сравнения) |
| `renders/m0.1_vs_m0.2_comparison.png` | M0.1 и M0.2 рядом |

## Что в сцене

- **12 домов** трёх типов: с консольным вторым этажом, двухэтажный с односкатной крышей, одноэтажный со стеклянной студией на крыше. У каждого светящиеся окна, дверь, навес, гараж, газон, подъездная дорожка, живая изгородь и дерево во дворе.
- **4 свободных участка**: грунт, золотая светящаяся пунктирная граница, колышки по углам и знак «+».
- **Дороги** с разметкой, тротуары с разрывами на перекрёстках, зебра.
- **Центральная площадь**: фонтан, золотое кольцо, скамейки, фонари.
- **Деревья**: низкополигональные кроны, есть розовые и золотые.
- Уличные фонари, набережная, озеро с отражениями, силуэт небоскрёбов за озером, холмы.
- **Освещение**: закатное небо (тёмно-синий → сиреневый → розовый → золотой), низкое золотое солнце с диском у горизонта, холодная синяя подсветка, тёплые окна и фонари.
- **Камера** `Cam_Reels`: 1080×1920, объектив 30 мм, вид сверху-сбоку через район на закат.
- **Рендер**: Cycles (CPU), 96 сэмплов, шумоподавление, цветовой профиль AgX, мягкое свечение (Glare) в композиторе.

Коллекции в сцене: `Houses`, `FreePlots`, `Roads`, `Plaza`, `Trees`, `Lamps`, `Lights`, `Ground`, `Background`.

## Как запустить

Нужен Blender 4.x (проверено на 4.2). Скрипт **очищает текущий файл** и строит сцену заново.

```bash
cd blender/episode-001
blender -b -P scripts/build_district.py -- \
  --save scenes/noc_ep001_district.blend \
  --render renders/m0.2_test_frame_1080x1920.png --samples 96
```

Другие параметры:
- `--preview` — рендер в половинном разрешении для быстрой проверки;
- `--samples N` — количество сэмплов;
- `--seed N` — другая случайная расстановка деревьев и окон.

Из интерфейса Blender: вкладка **Scripting** → открыть `build_district.py` → **Run Script**. Сцена будет построена, рендер и сохранение не запустятся.

Без установленного Blender можно использовать Python-модуль `bpy` (нужен Python 3.11):

```bash
python3.11 -m venv bpyenv && bpyenv/bin/pip install bpy==4.2.0
bpyenv/bin/python scripts/build_district.py --save ... --render ...
```

Рендер 1080×1920 при 96 сэмплах занимает около 3 минут 20 секунд на 4 ядрах CPU (сцена M0.2, 2185 объектов).

## M0.2 — Visual Polish

- **Дороги без чёрных провалов.** Причиной были совпадающие по высоте поверхности: два дорожных полотна на перекрёстке и угловые наложения тротуаров. Cycles рендерит такие места чёрными. Теперь на каждом перекрёстке есть приподнятая плита перекрёстка, а тротуары N–S дорог обрываются у внешнего края поперечных тротуаров, так что тротуары не перекрываются. Добавлены зебры, асфальт стал светлее, кварталы заполнены газоном.
- **5 типов домов** (тип в имени объекта `House_NN_<style>`):
  - `cantilever` — нависающий второй этаж с вертикальными ламелями;
  - `monopitch` — односкатная крыша, балкон со стеклянным ограждением;
  - `pavilion` — полностью стеклянный фасад, глубокий свес крыши, студия и пергола на крыше;
  - `gable` — современный «барн» с остеклённым фронтоном и белым флигелем;
  - `stacked` — смещённые объёмы, угловое остекление, терраса на крыше.

  Соседние дома всегда разного типа. Добавлены панорамное остекление с рамами, балконы, 6 палитр фасадов (белый, песочный, графит, серый, пудровый, кремовый) с акцентом из дерева или графита, навесы для машин вместо части гаражей.
- **Свет.** Небо глубже: золото у горизонта, коралловый, розовый, фиолетовый и тёмно-синий зенит. Солнце оранжевое. Окна теплее. Свечение (Glare) заметнее. По проходу тумана (Mist) добавлена лёгкая розовая дымка вдали, которая отделяет skyline от района.
- **Озеленение.** Цветущие вишни (на площади, набережной, во дворах, вдоль авеню), кустарники, клумбы у домов и вдоль улицы, цветочное кольцо вокруг фонтана.
- **Площадь.** Кольца мощения и радиальные швы, двухъярусный фонтан, скамейки со спинками, 4 кадки с вишнями, 12 светящихся столбиков.
- **Набережная.** Каменный променад и деревянный настил, ограждение со светящимися столбиками, кадки, скамейки, пирс с павильоном. Skyline отодвинут дальше, на дальнем берегу появилась линия деревьев.
- **Камера** ближе к району: неба меньше, в центре кадра площадь и дома.

## M0.3 — Cinematic Camera

`animate_camera.py` открывает готовую сцену и **не перестраивает район**. Он делает четыре вещи:

1. **Небольшие правки:**
   - окна мягче: сила свечения `window` уменьшена с 5,5 до 2,4, `window_soft` — с 3 до 1,6;
   - на переднем плане парковая полоса: дорожка, клумбы, кусты, светящиеся столбики, скамейки, вишни;
   - 12 точечных источников света под ранее неосвещёнными фонарями;
   - свечение (Glare) чуть мягче.

   Добавление геометрии помечено флагом в сцене (`noc_m03_polish`), поэтому повторный запуск не дублирует объекты.
2. **Камера `Cam_Cinematic`**: следит за объектом `Cam_Target` (ограничение Track To). Анимируются положение и фокусное расстояние (26 → 30 мм), интерполяция Bezier с ручками Auto Clamped. 360 кадров, 24 кадра/с, плюс ключ «разбега» до первого кадра, чтобы ролик начинался уже в движении.

   | Время | План |
   |---|---|
   | 0–4 с | Низкий проход вдоль домов на Front Street, высота 2 м |
   | 4–8 с | Наезд вверх по авеню к площади: фонтан, вишни, дома |
   | 8–12 с | Подъём с дугой влево: набережная, вода, skyline |
   | 12–15 с | Общий план на закате с мягкой остановкой |

   Старая камера `Cam_Reels` (кадр M0.2) сохранена.
3. **Проверка траектории** по всем 360 кадрам: лучи в 14 направлениях от камеры до ближайшей геометрии и профиль скорости.
4. **Рендер**: `--control-frames DIR` — 5 контрольных кадров, `--preview-video PATH` — MP4.

```bash
cd blender/episode-001/scripts
python animate_camera.py --check-only                       # только проверка траектории
python animate_camera.py --save ../scenes/noc_ep001_district.blend --control-frames ../renders/m0.3_control
python animate_camera.py --preview-video ../renders/m0.3_preview_540x960_12fps.mp4 --samples 8
```

Внимание: если заново запустить `build_district.py`, получится чистая сцена M0.2 без правок M0.3. После этого нужно снова запустить `animate_camera.py --save ...`.

### Движок

- **EEVEE Next** в облачной среде без GPU работает только через программную эмуляцию Mesa (llvmpipe). Для этого нужны маленькие системные пакеты `libegl1` и `libegl-mesa0`, а также переменная `EGL_PLATFORM=surfaceless`. Кадр 540×960 рендерится 13,5–17 с — медленнее Cycles, а отражения и дымка выглядят хуже.
- **Cycles CPU** с малым числом сэмплов и шумоподавлением OIDN: кадр 540×960 при 12 сэмплах — около 11 с, вид M0.2 сохраняется. Используется для превью. Опция `render.use_persistent_data` включена, так как между кадрами двигается только камера.
- На машине с GPU EEVEE станет основным вариантом для быстрых черновиков: `--engine EEVEE`.

## Следующие шаги (не сделано в M0.1)

- Анимация пролёта камеры для Reels: пока не рендерилась.
- Солнечный диск всё ещё скорее персиковый, чем золотой: AgX обесцвечивает яркие цвета. Следующий шаг — Color Balance в композиторе или отдельная маска для диска.
- Нижняя часть кадра (луг за Front Street) тёмная — кандидат на клумбы, дорожку или кадрирование.
- Больше деталей: машины, люди, вывески, мост через озеро, как на референсе.
