# RESIDENT #001 — ZHANABAEV: 3D avatar (M0.7)

Первый игровой житель NO ONE'S CITY. Стиль: Modern Stylized 3D × Premium Low-Poly × Cozy Cinematic.
Рост модели около 1,77 м с волосами. Это игровой масштаб, а не утверждение о реальном росте жителя.

**Референсы:**
- утверждённая карточка персонажа (три ракурса и детали);
- стилизованный портрет для пропорций лица.

Обе картинки использовались только в рабочей среде и **в репозиторий не добавлены**.

## Как открыть

- **Модель:** откройте `resident_001_avatar.blend` в Blender 4.2 или новее.
  - Камеры: `Avatar001_Front`, `Avatar001_Left`, `Avatar001_Back`, `Avatar001_ThreeQuarter`, `Avatar001_Portrait`. Чтобы смотреть через камеру: выделите её и нажмите Numpad 0.
  - Скелет: выделите `AV001_Rig` и перейдите в Pose Mode (Ctrl+Tab).
  - Исходная нейтральная поза — A-поза (руки примерно на 32° от вертикали). Увидеть её можно в свойствах скелета: Pose → Rest Position.
  - В файле сохранена поза `relaxed`.
- **Город:** откройте `episode-001/scenes/noc_ep001_district.blend`.
  - Аватар в коллекции `RESIDENT_001_AVATAR`, стоит у входа в Founder Residence 001.
  - Камеры: `Avatar001_*` и `Avatar001_AtResidence`. Камеры города и резиденции не менялись.

Все материалы процедурные, внешних текстур, шрифтов и аддонов нет.

## Модель

| Часть | Как сделано |
|---|---|
| Голова и лицо | Широкое округлое лицо с полной линией челюсти; уши, глаза (белок + радужка), густые прямые брови, нос (спинка, кончик, крылья), улыбка (линия рта, верхние зубы, нижняя губа) |
| Волосы | Короткий густой «ёжик» с фактурой сверху; короткие тёмные бока и затылок |
| Очки | Тонкая золотая прямоугольная оправа: ободки, перемычка, носовые упоры, шарниры, дужки до ушей; отдельные коричневые полупрозрачные линзы |
| Тело | Шея, открытая кожа в вырезе ворота, руки, предплечья, кисти (ладонь, 4 пальца, большой палец) |
| Одежда | Белая рубашка навыпуск: подол, планка, 5 пуговиц, стойка и отложенные концы воротника, рукава закатаны до предплечья; тёмные зауженные брюки |
| Обувь | Белые кроссовки: верх, подошва, язычок, шнурки |
| Аксессуары | Стальные часы на левом запястье: браслет, корпус, безель, тёмный циферблат |

## Скелет

| Цепочка | Кости |
|---|---|
| Корпус | `Root` → `Pelvis` → `Spine` → `Chest` → `Neck` → `Head` |
| Руки | `Shoulder.L/R` → `UpperArm.L/R` → `Forearm.L/R` → `Hand.L/R` |
| Ноги | `Thigh.L/R` → `Shin.L/R` → `Foot.L/R` |

Привязка (веса):
- одежда и кожа — плавные веса по расстоянию до костей, не больше двух костей на вершину и только из списка, разрешённого для этой части тела;
- голова, лицо, волосы и очки жёстко привязаны к `Head`;
- обувь — к `Foot`, часы — к `Forearm.L`.

Позы в `avatar_core.POSES`: `neutral` (исходная), `relaxed`, `test_arms`, `test_head_legs`. Анимация ходьбы пока не делалась.

## Для следующих жителей

Общая логика лежит в `avatar_kit/avatar_core.py`; всё индивидуальное — в JSON-конфиге:

| Что меняется | Где в конфиге |
|---|---|
| Пропорции тела и рост | `height`, `build.*` (ширина плеч, грудь, талия, бёдра, толщина рук и ног) |
| Лицо | `face.*` (ширина, высота и глубина головы, челюсть, подбородок, щёки, брови, нос, улыбка, цвет глаз) |
| Причёска | `hair.style`; сейчас есть `short_textured_fade` и `buzz`, новые добавляются в `build_hair` |
| Очки | `glasses.style`, цвет оправы и линз, затемнение; `"none"` убирает очки |
| Одежда | `outfit.shirt`, `outfit.trousers`, `outfit.shoes` — фасон и цвета |
| Аксессуары | `accessories` — список; сейчас есть `watch` с выбором руки и цветов |
| Размещение | `placement.anchor` (корень участка), `local_offset`, `rotation_z_deg`, `pose` — переезд на другой участок без правки кода |

Пересборка:

```bash
cd blender/residents/001_zhanabaev/avatar
python build_avatar.py --studio --save resident_001_avatar.blend --previews previews --report previews/avatar_check_report.json
python build_avatar.py --city ../../../episode-001/scenes/noc_ep001_district.blend --previews previews --report previews/avatar_check_report.json
```

Повторный запуск заменяет прежнюю коллекцию аватара; дублей не остаётся.

## Ограничения сходства

Это процедурная стилизованная модель. Она передаёт узнаваемые черты по карточке, но **не является точной копией лица**:
- глаза почти скрыты тонированными линзами, поэтому форма глаз и век упрощена;
- лицо собрано из деформированной сферы: нет морщинок у глаз, носогубных складок и мягкого второго подбородка;
- брови — простые объёмные полосы без отдельных волосков;
- улыбка неподвижна, без мимических костей;
- кисти упрощены, пальцы не анимируются отдельно.

Точечные улучшения без переделки проекта описаны в отчёте M0.7.
